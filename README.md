# Paperflip 紙

A calm, fast, private notebook for Linux. Made by **Samarth Rao** (サマルト・ラオ).

- Markdown notes with notebooks, tags and statuses
- Saved on your computer first; optional sync to your own Google Drive
- A private AI assistant that runs entirely on your computer
- Ink-and-paper design, light and dark

## Download

Grab **Paperflip-x86_64.AppImage** from the [latest release](https://github.com/samarthrao34/paperflip-releases/releases/latest), then:

```bash
chmod +x Paperflip-x86_64.AppImage
./Paperflip-x86_64.AppImage
```

Paperflip updates itself: when a new version is out, open **Settings → Updates** and click **Install update**.

Each release includes a `.sha256` checksum file.
